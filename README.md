# Legal Document Analysis and Q&A using RAG Framework

## Project Overview

This project is an AI-powered Legal Document Analysis system that uses Retrieval-Augmented Generation (RAG) to answer user questions based on uploaded legal documents. The system retrieves relevant information from the documents and generates accurate, context-aware responses using Large Language Models.

## Features

- Upload legal documents (PDF)
- Extract document text
- Generate embeddings
- Store embeddings using FAISS
- Retrieve relevant document sections
- AI-powered Question & Answer system
- User-friendly web interface

## Technologies Used

- Python
- Django
- LangChain
- FAISS
- Hugging Face Transformers
- TensorFlow
- Sentence Transformers
- HTML
- CSS
- JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/YourUsername/Legal-Document-Analysis-RAG.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python manage.py runserver
```

Open in browser:

```
http://127.0.0.1:8000/
```

## Project Workflow

1. Upload legal documents
2. Extract text from documents
3. Create embeddings
4. Store embeddings in FAISS
5. User enters a legal query
6. Retrieve relevant document chunks
7. Generate an AI-powered response
8. Display the answer
